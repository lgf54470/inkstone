## 不做清单（P3，已决策并逐条给出计划，2026-09-29 收束）

五项都是**判定不做**，不是「延期」：每项在下面写明它是哪种约束、若要做时的落点与先红测试、成本量级，以及**什么信号下值得重开**——这样决定是可逆的、知情做出的，而不是一句「本轮不做」。判定为「不做」的项不占本文件的待办，因此不再用 `[ ]`；重开时当作新条目立，附上触发它的证据。

- **IMP-13 响度归一化 RMS→LUFS —— 判定：不做（成本收益不成比例，保持 RMS 近似）**
  - 约束类型：工程成本。现有 RMS 近似已能抹平大部分曲目间的响度差，剩下的差异只出现在动态范围大的曲目上。
  - 若要做：按 ITU-R BS.1770-4 实现 K 加权（双二阶预滤 + RLB 高通）、400ms 滑动窗 + 绝对/相对门限，若要报 LRA/真峰还需 4× 过采样。落点是播放链上那枚增益节点（EQ、交叉淡入淡出、响度归一化同挂 `MediaElementSource`，见 IMP-9 的改判说明）；每首的响度值宜离线算一次并缓存，复用 `music-store` 的持久化通道，避免每次播放重算。
  - 先红测试：纯函数可测（合成正弦/粉噪 → 已知 LUFS → 目标增益），落在 node/jsdom 下；端到端不可测（引擎在本机无声音断言，与前两轮同）。
  - 成本：中–大（2–4d，含缓存与首播分析的主线程预算）。引第三方 DSP 库须按铁律 8 评估体积、许可证与供应链。
  - 重开信号：读者反馈「同一歌单里音量差得明显」，且用分析脚本量出一批曲目的 RMS 近似偏差 >3 LU。
- **IMP-14 10 段 EQ —— 判定：不做（独立产品决策，本轮不做）**
  - 约束类型：产品决策，不是技术缺口。现有 5 预设（`music-eq-presets.ts`）覆盖「按类型整体调」的用法。
  - 若要做：10 段（31.5Hz–16kHz）IIR peaking 滤波器链 + 预设体系扩容 + 频段矩阵 UI（设置页与沉浸层两处，窄屏必须换档——本轮已在「宽容器才换挡」这一类上踩过一次）+ 持久化 schema 迁移（现有字段是预设名 + 单一增益）。
  - 先红测试：滤波器系数与响应曲线纯函数断言、设置页交互用例、旧偏好读入后的迁移用例。
  - 成本：中（1–2d DSP 与迁移、1–2d UI），主要风险在窄屏可用性。
  - 重开信号：出现按频段微调的真实需求（针对特定耳返/音箱/房间），且 5 预设无法近似。
- **IMP-15 crossfade 期间画面跟随 —— 判定：不做（画面重影、可读性更差，保持硬切）**
  - 约束类型：体验判断。交叉淡入淡出期间新曲画面与旧曲画面重叠即重影，比硬切更难读。
  - 若要做：不是「加一层过渡」，而是把**当前音频源**与**当前画面源**拆成两个状态，让画面绑定音频源而不是当前曲——封面、歌词、可视化都要跟着改绑定；音频侧继续交叉淡入淡出，画面侧等音频完成后整块切换（或淡入到空屏再入新画面）。
  - 先红测试：状态层用例（crossfade 进行中读画面源仍是旧曲；结束后是新曲）+ 播放器表面用例。
  - 成本：大（跨 state 与多个表面）。收益仅在可视化/视频播放面连续过渡时才显现。
  - 重开信号：出现可视化或视频播放面，且需要连续过渡。
- **IMP-16 KV 单值 25MiB —— 判定：不做（平台限制）**
  - 约束类型：平台限制（Cloudflare KV 单值上限），不可能靠「调大」解决。
  - 若要做：换存储或分片，而不是提高上限——超阈值的媒体走 R2（`FILES` 绑定，KV 模式下的 `FILES_KV` 是无 R2 时的退路），或按块分片存 KV 并在读取端透明重装；两种都要给读取路径一个「同一逻辑对象」的表象，并写迁移把已超限的对象搬到 R2。客户端侧的离线副本本就在 IndexedDB/SW 缓存里，与这条无关。
  - 先红测试：worker 契约用例（超限时的路由选择、分片写入与读取重装、迁移幂等）。
  - 成本：中（1–2d，含迁移与回滚说明）。
  - 重开信号：上传路径真的出现 >25MiB 的单曲（无损音频是目前的典型触发点）。
- **IMP-17 WebDAV 后台缓冲 —— 判定：不做（浏览器约束）**
  - 约束类型：平台能力。Service Worker 会被浏览器回收、页面关闭即停，Web 端没有真正的后台下载保证。
  - 若要做：把「后台」降级为**可续传的前台任务**——Range 请求 + 断点续传 + 进度落库（IndexedDB），重开页面接着下；SW 只负责命中缓存，不承担常驻下载。要真后台必须走原生端，本项目没有。
  - 先红测试：断点续传的契约/纯函数用例 + 中断后恢复的 store 用例。
  - 成本：中（1–2d）。
  - 重开信号：读者抱怨「必须开着页面才能下完」，且接受「重新打开页面继续」。
