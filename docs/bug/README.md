## 撰写规范

每篇 Bug 复盘报告应遵循以下标准章节结构：
1. **问题描述**：发生环境、现象表现、报错日志、复现路径与截屏/堆栈
2. **根本原因 (Root Cause)**：深入到底层运行机制（V8、网络、浏览器渲染、SSR/Hydration、时区等），解释"为什么会发生"
3. **如何解决**：具体的修复代码比对、架构调整说明及关联 commit
4. **验证过程**：本地沙箱复现验证、CI 自动化测试与生产线上验证结果
5. **后续如何避免**：总结规范红线、静态门禁、自动化测试建议与工程化防护机制
